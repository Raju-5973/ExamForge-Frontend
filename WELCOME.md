### First Time? Try This:

1. **Open the application** in your browser
2. **Click "Load Demo Questions"** on the login page
3. **Register** as either:
   - **Staff** (to manage questions)
   - **Principal** (to generate papers)
4. **Explore** the dashboard and features

### Want to Test Everything?

Create TWO accounts:

## 📚 What Each Role Can Do

### 👨‍🏫 Staff Role
**Perfect for teachers and content creators**

✅ Add new questions to question bank  
✅ Edit existing questions  
✅ Delete questions  
✅ Organize by subject and difficulty  
✅ Set custom marks for questions  
✅ View complete question bank  

**Cannot:** Generate question papers

### 👔 Principal Role
**Perfect for administrators and exam coordinators**

✅ View question bank statistics  
- ✅ Subject dropdown (10 subjects available)  
✅ Define marks distribution  
✅ Generate custom question papers  
✅ Download papers as PDF  
✅ Print professional exam papers  

**Cannot:** Add or edit questions
