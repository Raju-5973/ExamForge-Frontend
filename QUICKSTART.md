# Quick Start Guide

Get up and running with the Question Paper Generator System in minutes!

## 🚀 First Time Setup

### Option 1: Load Demo Data (Recommended for Testing)

1. Open the application in your browser
2. On the login page, click the **"Load Demo Questions"** button
3. This will populate the system with 20+ sample questions across all subjects
4. Now you can register and login to explore all features

### Option 2: Start Fresh

1. Register a new account (choose either Staff or Principal role)
2. Login with your credentials
3. Start adding questions or generating papers

## 👥 User Roles Explained

### Staff Role
**What you can do:**
- ✅ Add new questions to the question bank
- ✅ Edit existing questions
- ✅ Delete questions
- ✅ View all questions organized by subject
- ❌ Cannot generate question papers

**Ideal for:** Teachers, professors, content creators

### Principal Role
**What you can do:**
- ✅ View question bank statistics
- ✅ Generate custom question papers
- ✅ Download papers as PDF
- ✅ Print question papers
- ❌ Cannot add/edit questions

**Ideal for:** Administrators, exam coordinators, principals

## 📝 Common Workflows

### As a Staff Member

1. **Login** with Staff role
2. **Add Questions:**
   - Fill in question text
   - Select subject
   - Choose difficulty (Easy/Medium/Hard)
   - Set marks (2, 5, 10, etc.)
   - Click "Add Question"
3. **Manage Questions:**
   - Review your questions in the Question Bank
   - Edit by clicking the edit icon
   - Delete by clicking the trash icon

### As a Principal

1. **Login** with Principal role
2. **Check Statistics:**
   - View available questions per subject
3. **Generate Paper:**
   - Select a subject
   - Add marks distribution rows:
     - Example: 2 marks → 5 questions
     - Example: 5 marks → 3 questions
   - Click "Generate Question Paper"
4. **Download/Print:**
   - Review the generated paper
   - Download as PDF or print directly

## 🎯 Sample Use Case

**Scenario:** Generate a Mathematics exam worth 25 marks

**Steps:**
1. Login as Principal
2. Select "Mathematics"
3. Add distribution:
   - Row 1: 2 marks, 5 questions (10 marks total)
   - Row 2: 5 marks, 3 questions (15 marks total)
4. Click "Generate Question Paper"
5. Result: Professional exam with 8 questions totaling 25 marks

- **Plan Ahead:** Know your exam structure before generating
- **Check Availability:** Review the statistics to ensure enough questions exist

## ❓ Troubleshooting

**Q: I can't see any questions to generate a paper**
- A: Make sure questions exist for the selected subject. Login as Staff to add questions.

**Q: Generation fails with "Not enough questions"**
- A: Reduce the number of questions requested or add more questions to the bank.

**Q: My data disappeared**
- A: Data is stored in browser local storage. Clearing browser data will reset the app.

**Q: PDF download not working**
- A: Use Chrome browser for best PDF generation support.

**Q: Can I export my questions?**
- A: Currently not supported, but data is in localStorage (check browser DevTools).
